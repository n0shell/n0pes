## 🎮 ¿Qué es esto?

Un script / app rápida montada específicamente para llevar el control, tablas o gestión de un **torneo casual entre colegas**. 

* **Estado:** 100% Terminado.
* **Futuro:** Este repositorio se autodestruirá / borrará en cuanto termine el torneo y ya no haga falta.
